# デザイン手法・トレンド データベース

必要なときだけ引く、月次更新の参照用データベースです。1 項目 1 ファイルで、ID は月をまたいでも変えていません。

取得の起点は 2026-10-31（JST）です。X の反応数は同日 12:45 JST 頃のスナップショットです。日時は JST に変換済みで、変換していないものは（UTC）と書いています。L はいいね、RT はリポスト、V は表示回数、BM はブックマークです。

## スキルからの引き方

design-nexus がこのディレクトリを開くのは、ヒアリングでユーザーが流行を取り入れたいと分かったときだけです。分かっていなければ開きません。AGENTS.md と CLAUDE.md からは読み込みません。

読む順は次のとおりです。

1. [latest.md](latest.md) — 直近月の短い要約
2. [index.md](index.md) — タグと、全月の ID 一覧
3. `trends/` の該当ファイルだけ

確度が「低」「低〜中」、または「未確認」の項目は、根拠が弱いので採用の前提にしません。T11、T12、T18 はとくにその旨を本文に残しています。

## 採用前の評価

候補を本文まで読んでも、そのまま採用しません。このプロジェクトに効くかを、次の順で判断します。

- 目的、想定する人、ブランドに合うか
- アクセシビリティと性能を悪くしないか。悪くするなら、そのコストをこの画面で受け入れられるか
- 確度が採用の前提に足りるか。低、低〜中、未確認は理由になりません
- 状態が fading や dropped ではないか。`#mature` は、目新しさの根拠にしない
- `#anti-pattern` は、警告されている見た目を採用しない。項目自体が避け方を書いている場合（T01）は、その避け方を採用してよい
- 本文の「避ける場面」に当てはまらないか

通ったものだけを採用し、採用したものもしなかったものも、理由を一文で残します。どれも通らなければ、何も採用しません。

## 引き方

ID（例: `T08`）、名前（例: 分解図）、タグ（例: `#motion`）で探します。タグから ID へは [index.md](index.md) のタグ索引、ID から本文へは同じファイルの ID 索引です。本文は `trends/T08-exploded-view.md` のように、ID とスラッグのファイル名です。

各項目の書式は同じです。ID、タグ、概要、特徴・適用方法、向く場面、避ける場面、代表例、ソース、トレンド時期、確度、状態、更新履歴。

## 状態

index.md の「状態」は、その月の本文から付けたラベルです。付けた理由は各ファイルの更新履歴に残しています。

| 状態 | 意味 |
|---|---|
| rising | 直近で言及や反応が増えている |
| steady | 続いている。急増とは書いていない |
| mature | 定番化している。新規の差別化にはなりにくい |
| fading | 言及が落ちた、または「もう古い」という材料がある。ファイルは残し、latest にも状態つきで残す |
| dropped | 根拠が否定された、重複だった、見送りに落とした。ID は再利用しない。latest からは外し、index と本文は残す |

## 月次の更新

手順の全体は [COLLECTING.md](COLLECTING.md) です。月が変わると `monthly/YYYY-MM.md` を 1 枚足し、latest.md をその月の要約に差し替え、index.md の行を更新します。新しい手法は新しい ID です。次の空きは **T19** です。既存の ID は変えません。

2026-10 の収集範囲、検証方法、見送りと保留は [monthly/2026-10.md](monthly/2026-10.md) です。

## インストール後の場所

正本はこのディレクトリ（リポジトリの `docs/design-trends/`）です。Claude Code のプラグインはリポジトリ全体が対象なので、同じパスにあります。

`./install.sh` は `scripts/build.mjs` がスキルの隣へコピーしたツリーを配ります。

| 入れ方 | 読む場所 |
|---|---|
| このリポジトリ、または Claude Code プラグイン | `docs/design-trends/` |
| Claude Code / Codex の install.sh | スキル直下の `design-trends/` |
| Cursor の install.sh | `.cursor/design-nexus/design-trends/` |

スキルは、`docs/design-trends/latest.md` があるときはそちらを読み、無いときだけスキル隣のコピーを読みます。コピーは生成物なので、項目の編集はこちらだけにします。
