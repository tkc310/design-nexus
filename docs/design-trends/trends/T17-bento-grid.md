- **概要**: 大きさの違うタイルを格子状に並べる構成。すでに定番で、AI の既定レイアウトとも重なりやすい。
- **特徴・適用方法**: 情報の重要度に合わせてタイルのサイズに差をつけ、スムーズな動きを加える。

- **避ける場面**: タイルの大きさがすべて同じになるとき（AI スロップの「同じ形のカード」と同じになる）。
- **代表例**: レイアウト名としての bento。ソースに挙がる制作ツールは Framer です。
