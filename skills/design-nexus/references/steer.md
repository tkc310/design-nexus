# Steering vocabulary

Short commands for adjusting an existing design. Each changes the smallest set of tokens or rules that achieves it, then re-runs the lint. Combine freely ("bolder, but quieter motion").

| Command | Does | Typical levers |
|---|---|---|
| bolder | More contrast and conviction | Larger display size step, heavier weight, stronger accent area, bigger signature |
| quieter | Less noise | Remove decoration, reduce accent use, lighter weights, fewer sizes |
| distill | Fewer elements | Cut a section, merge similar items, remove one accessory per pass |
| colorize | Introduce or strengthen color | Add a second accent role or tint surfaces; keep contrast |
| typeset | Improve typography only | Re-pair faces, fix scale, measure, line-height, numerals |
| relayout | Change structure, keep content | New layout concept and wireframe; re-verify responsive |
| animate | Add purposeful motion | One orchestrated moment; read `motion.md` |
| de-animate | Remove motion | Delete decorative motion, keep feedback and continuity |
| densify | More information per screen | Smaller spacing steps, compact rows, tabular data |
| airy | More breathing room | Larger spacing steps, wider margins, fewer items per row |
| polish | Finish-tier pass | Fix N-series and alignment, states, copy |
| harden | Production readiness | Worst-case data (very long names, huge counts, empty lists, missing images), overflow, empty/error/loading states, i18n, a11y |

After steering, update DESIGN.md if a token changed.
