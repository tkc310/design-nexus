Build the "Notifications" settings page for a project-management web app. Users choose, per channel (email, push, Slack), which events notify them: mentions, assigned tasks, due-date reminders, weekly digest. Include a quiet-hours time range with timezone, a "Send test notification" action, inline validation (quiet-hours end must differ from start), a save flow with success and failure feedback, and a disconnected-Slack state that offers to connect.
