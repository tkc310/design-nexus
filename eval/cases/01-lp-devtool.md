Build a landing page for "grepline", an open-source CLI that searches structured logs (JSON, logfmt) across many files with a SQL-like filter syntax. Audience: backend and SRE engineers. Single job: get them to run the install command. Real facts you may use: written in Rust, MIT licensed, 1 binary, installs with `cargo install grepline` or `brew install grepline`, filters like `level=error and latency_ms>500`. No customer logos or testimonials exist.
