Search JSON and logfmt logs with a WHERE clause.

grepline reads every file you give it, treats each line as a record, and prints the ones your filter keeps. One Rust binary, MIT licensed.

install

brew install grepline
cargo install grepline

Try a filter on an incident's logs

$ ' logs/*
