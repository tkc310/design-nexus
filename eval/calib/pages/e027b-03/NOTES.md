# NOTES — 03-dash-clinic「今月の給与」

Budget: standard / surface: product / mode: build (+ DESIGN.md written here).

## Ground
- Subject: 小規模クリニック(15〜40名)向け給与計算SaaSの「今月の給与」画面。
- Audience: 受付や請求業務の合間に給与を回す事務長・院長。会計の専門家ではない。支給ミスと締め遅れを恐れている。
- Job: 締め日までに今月の給与を確定する(先に、確定を止めている勤怠申請を承認する)。
- Primary action: 「勤怠を承認する」が未承認のある間の唯一の塗りボタン。「給与を確定する」は同じ位置に無効表示で置き、理由を横に書く。承認と再計算が済むと確定ボタンが塗りに変わる。

## Usual look
白か薄いグレーの地、Noto Sans JP/Inter系のグロテスク、大きな数字のKPIカードの列、青い主ボタン、縞のテーブル、柔らかい影の白カード。

## Three directions
- A —「給与明細書」: 支給・控除・差引の枠が印刷された給与支給明細書。白い帳票地に罫線の表が主役。→ 普段の「白地に表」に近すぎ、離れるのは書体だけ。
- B —「タイムカードとラック」(採用): 通用口のスチールラックに差したタイムカード。ドットインパクトで紫(通常)と赤(要注意)に印字される日付列が主役。中間調の地、ドット書体、印字された日の列というデータマーク、ラックに立つ紙の面。
- C —「カルテ棚の色分けラベル」: カルテフォルダの背に貼る彩度の高い色ラベル。職種ごとの強い色帯で一覧を組む、賑やかで高彩度の方向。→ ユーザーが操作しない分類に色を使ってしまう。

## Chosen: B「タイムカードとラック」
普段の見た目から、地の明度(中間調のスチールグレー #A9B2AC)、表示書体のジャンル(DotGothic16 のドット書体)、主データマーク(締め日までの日の列)、面(ラックに立つカード紙のパネル、実際の影)の4点で離れる。
- 紫の印字 → 済んだ日・主操作の色(#4A2D80)。赤の印字 → 「確定を止めているもの」だけ(未承認の件数・時刻、要再計算、締め日)。
- カードの印刷罫・二重罫の見出し行 → パネル見出しとテーブル/合計表の罫。
- カードが期間のすべての日を並べる習慣 → シグネチャの日の列。
- アクセント候補: 紫の印字(採用、「記録された・済んだ」を意味する)/赤の印字(状態色として温存)/ラックのスチール(中立すぎて操作の色にならない)。
- 表示書体候補: DotGothic16(ドット、採用:印字そのもの)/ 等幅スラブ / コンデンスのグロテスク。本文は BIZ UDPGothic(UD書体、疲れた目に読みやすい)。
- コピーに入れない語: タイムカード、カード、ラック、打刻、リボン、インク、パンチ、印字。

## Signature
「確定の締め日まで あと5日」と、その下の日の列(11/1〜支給日11/25の25日)。過ぎた日は紫の数字と短い線、今日は紫の塗り、残りは破線の空き枠、締め日は赤枠、締め後〜支給日は沈んだ地、支給日は紫枠。未承認の申請が届いた日には赤い点。
同じ「1日の単位」を、未承認申請の各行の先頭(勤務日のセル、赤い数字)とスタッフ表の赤い点のフラグに再利用している。
