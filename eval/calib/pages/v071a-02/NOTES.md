# NOTES — 土と灯 トップページ

Budget: standard / surface: marketing / mode: build(DESIGN.md を新規作成)

## Ground
- Subject: 京都・五条坂の陶芸工房「土と灯」。職人2名、日常の器と月2回の手びねり教室(各回6名まで)。
- Audience: 30〜50代の国内外の旅行者。五条坂・清水寺の散策と組み合わせて、手を動かす体験を探している。
- Job: 体験教室の予約ページ(/reserve/)へ送る。

## 考えた3つの方向
- A —「テストピース盤」: 工房の土壁に吊るす釉薬の試験片(吊り穴・素地の上部・下2/3の釉・鉄絵の筆書き)を単位にする。中明度の聚楽土の壁、筆文字+角ゴシック、実物の板に実影。試験片の盤がヒーロー。
- B —「窯の灯」: 窯焚きの夜、色見穴からのぞく火。暗い地に炎の色、明朝の大見出し、写真主導のフルブリードの連続。屋号の「灯」から。
- C —「窯焚き帳」: 窯焚き記録と注文帳。明るい紙地、罫線と表、等幅の数字で日程表を主役にする。

## 選んだもの
A「テストピース盤」。理由:教室で参加者が実際に「壁の試験片から釉薬を選ぶ」ので、ページの単位がそのまま体験の一場面になる。B は暗地+炎色で R04b に寄り、写真素材がまだない現状では成立しにくい。C は罫線・紙地・等幅数字でハウスルック(R04d)に寄る。

- 地:聚楽土の壁色 #C4B08C(京都の土壁)。読む帯は白釉 #EEEBE3。
- アクセント候補:呉須(藍, ~225°)/辰砂(銅赤, ~0°)/青磁(低彩度の青緑)→ 呉須。黄土の地に対して補色で、予約という一つの行動が埋もれない。京焼の日常の器を彩ってきた顔料でもある。辰砂は警告色に見え、暖色の地で沈む。青磁は地とのコントラストが足りない。
- ディスプレイ候補:筆書体 Yuji Syuku/明朝 Shippori Mincho/角ゴシック太字 → Yuji Syuku。試験片や箱書きの鉄絵・墨の筆跡が、この工房自身の文字だから。本文は Zen Kaku Gothic New(400/700)。Google Fonts で読み込み、display=swap。
- 計画の見直し:ヒーローを「見出し+写真」から試験片の盤に変更。最後の CTA を暗い帯にせず、呉須の釉が掛かった大きな試験片にした。

## シグネチャー
ヒーローの「試験片の盤」:桟と釘に吊るした6枚の試験片(白釉・青磁・飴釉・呉須・天目・辰砂)。筆の縦書きで釉名、釉の部分に一言。同じ単位を次の場所で再利用している:
- 日程:1回=1枚の試験片(素地部分に日付、釉の部分に時間・6つの席の印・予約ボタン。満席の回は天目の黒)
- 体験の流れ:各ステップの印が、湿った土 → 素地 → 半分施釉 → 焼成済み、と試験片の状態で進む
- 器の棚札、職人の印、最後の「次回の教室」CTA(呉須の釉が掛かった大きな試験片)

## Reflex の扱い
- 保持した Reflex はなし(lint・render とも Reflex 0)。
- R04a(暖かいクリーム+高コントラスト明朝+テラコッタ)には寄せていない:地は中明度の土壁色、本文はゴシック、行動色は藍。
- R11:流れの 1〜4 は実際の順序なので番号を使っている。

## ツールの結果(最終)
- lint: floor 0 · reflex 0 · finish 0(`--design DESIGN.md` 付き)
- render: floor 0 · reflex 0 · finish 0(320 / 768 / 1280 / 1920)
- tokens-check: 0
- 修正ラウンド:1回目に F09(320/768 でナビ「器」のタップ領域 16px)を修正。批評で直した3点:1280 で流れの4列が狭く見出しが3行に割れていた → 試験片を上に積む形に変更/320 で釉の一言が語の途中で折れていた → 余白と字間を調整/768 でヒーローの盤が左に寄って右が空いていた → 6枚を1段に。320 でナビが2行になっていた → 「教室の日程」を「日程」に短縮。
- 外した装飾:キャプション前の呉須の四角。

## 写真プレースホルダー
写真はまだないため、ブリーフの指示どおり、斜線の枠に「写真準備中|(撮る予定のカット)」と明示した。4か所:飯碗を真横から/湯呑と手/小皿を重ねて/作業台と窯、奥に試験片の壁。差し替えるときは `.photo` の div を `<img width height alt>` に置き換える。
