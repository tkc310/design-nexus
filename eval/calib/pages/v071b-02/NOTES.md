# NOTES — 土と灯 トップページ

Budget: standard / surface: marketing / mode: build (+ DESIGN.md を新規作成)

## Ground

- Subject: 京都・五条坂の陶芸工房「土と灯」。職人2名、飯碗・湯呑・小皿、月2回・各回6名までの手びねり教室。
- Audience: 30〜50代の国内外の旅行者。滞在中の半日で参加したい。空き・所要時間・言葉が気になる。
- Job: 体験教室の予約ページへ送る。

## Three directions considered

- A —「窯の夜」: 窯の内壁の煤色を全面の地にし、覗き穴の火を灯色に。全面ダークの連続セクション、明朝見出し、写真主導。→ 写真がまだ無く、ダーク+単一の暖色アクセントは R04b に近い。
- B —「白化粧と呉須」: 白化粧の明るい地に呉須の藍。器のカタログを格子で並べる、ゴシック主体。→ 予約という仕事より物販に寄り、藍の一色アクセントはハウスルック(R04d)に近い。
- C —「席の灯」(採用): 濡れた京都の土の灰色(中間調)を地に、窯色のパネル1枚だけ。工房名の「灯」を空席の印として灯す。見出しは箱書きの筆文字。予約ボードがヒーロー。

採用理由: ページの仕事(予約)と工房名(土と灯)が同じ図になる。予約済みの席=土、空いている席=灯。

Accent candidates: 灯(覗き穴の火・工房名)/ 青磁(清水焼の釉)/ 呉須(染付の藍) → 灯。空席=行動できる場所、という意味を持たせられるのは工房名そのものの「灯」だけ。青磁は「空き」の意味を運ばず、呉須は藍一色のハウスルックに寄る。
Display candidates: 筆(Yuji Syuku — 箱書き・木札)/ 明朝(Shippori Mincho — 栞)/ 丸ゴシック(Zen Maru Gothic) → 筆。器の箱に職人が筆で書く文字が、この工房自身の書き文字だから。本文は Zen Kaku Gothic New。

## Signature

**席の灯ボード**(ヒーロー右、320pxでは見出しの直下・初期表示内)。各回6つの「高台」(器を裏から見た縁+高台の輪)。予約済みは焼締色、空席は灯色で光る。
単位=高台の輪。再利用: 体験の流れ(土の塊→縁→高台→灯)、器の実寸比較(飯碗・小皿・湯呑を裏から見た輪、実寸比)、職人紹介の印、締めの「あと2席」の輪。
