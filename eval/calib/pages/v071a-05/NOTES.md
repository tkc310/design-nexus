# NOTES — ぐるりんバス時刻表（mobile / standard）

Budget: standard. Surface: mobile. Mode: build（DESIGN.md はこのフォルダに新規作成）。

## Ground
- Subject: 地方都市のコミュニティバス（循環1系統・12停留所）の停留所別時刻表。
- Audience: 高齢の利用者が多い住民。スマートフォンのブラウザで、停留所や出かける前に見る。
- Job: 選んだ停留所から次のバスが「あと何分」で出るかを知る。

## 3つの方向
- A —「標柱の時刻表板」: 停留所ポールの時刻表板（白い琺瑯・黒罫・時の列・分の並び）と点字ブロックの黄色を借りる。先頭は黄色セルの「あと◯分」板。明るい無彩色の地、sign-gothic 数字、フラットな罫。
- B —「車内の行先LED」: 車内・車外の行先表示器の暗い地とアンバーのドット数字を借りる。先頭は暗い盤面に光る大きな残り分数。暗い地、mono/ドット、密度高め。
- C —「回数券の綴り」: 回数券・乗車券の紙色とミシン目を借り、1便ごとに券片のカードを横に並べる。中間調の紙の地、slab 数字、影のあるカード。
- 採用: A。利用者は停留所で毎日この板を読んでいるので、同じ「時｜分」の形なら学び直しがいらない。黄×黒は弱視者向けに作られた配色そのもの。B はドット数字が高齢者に読みにくく、C は横スワイプが要る。

## トークンの選択
- アクセント候補: 点字ブロックの黄 #FFD100（彩度の高い信号色）／車体の緑 #00694B（落ち着いた塗装色）／時刻表板のアルミ灰（ほぼ無彩色）。→ 黄を「次に乗る便」に。利用者が行動する対象で、視覚障害者誘導用の色という由来が高齢者配慮と一致する。緑は構造（帯・時の列）に回した。灰は意味を持てないので枠の面に。
- 数字の書体候補: Overpass（道路標識ゴシック由来）／Zen Maru Gothic（丸ゴシック、コミュニティバスの車体文字）／Barlow Condensed（行先表示器のような長体）。→ Overpass。停留所の時刻表板の数字は標識系ゴシックで、長体は高齢者に読みにくく、丸ゴシックは数字の判別が甘い。本文は公共情報向けの UD 書体 BIZ UDPGothic。
- 本文 18px、最小 16px。タップ領域 52px 以上（select は 64px）。「文字を大きく」で 125%。ダークモードは別パレット。

## シグネチャ
「次のバス」板。左に黄色セルの「あと◯分」（先頭の便は 56px）、右に発車時刻。単位は「左の色セル＋右の本文、2px 黒罫で区切った行」で、同じ単位を運休行（赤セル）、お知らせ（赤＝運休／黒＝のりば変更）、全時刻表（緑の時セル）でも使う。次の3本の間にある運休便は、その位置に赤い行で挟んで見せる（待っても来ないことがわかる）。

## Reflex findings
lint・render とも floor 0 · reflex 0 · finish 0。残した Reflex はなし。

## 状態とその出し方
- 時刻はスマートフォンのタイムゾーン設定に関係なく日本時間で計算。15秒ごとと、画面に戻ったときに更新。
- 平日／土日祝: 当日の種別（土日・祝日一覧で判定）を初期表示。もう一方に切り替えると「平日ダイヤを表示しています。きょうは土日祝ダイヤです。」と出し、発車ずみ・次の便の印は付けない。
- 運休: 日付と便（駅発時刻）で持つデータから、次の3本の間・時刻表・お知らせ欄に反映。11月1日(日) は 9時台・10時台の便が運休（このデータで既定表示に運休行が出る）。11月5日(木) は 13:00 便。
- のりば変更: 11月2日〜13日の「中央公園前」の臨時のりば。
- お知らせなし: 今日から14日先までに該当がなければ「いまのところ、運休やのりば変更の予定はありません。」の行。
- 終発後: 「きょうの運行は終わりました。」＋翌日以降の3本（「明日」タグ）。始発前は時間単位の「あと4時間8分」と「始発」タグ。
- 年末年始（12/29〜1/3）: 「きょうは年末年始のため運休です。」＋次の運行日の3本。
- 停留所と文字サイズの選択は localStorage に保存（使えない環境でも動く）。

## 既定表示について
render check を走らせた時点は日本時間 11月1日(日) 4時台なので、既定のスクリーンショットは始発前（あと4時間〜、運休行2本を挟む）。平日昼の典型状態は `--time 2026-11-02T14:23:00+09:00 --tz Asia/Tokyo` で確認し、こちらも floor 0 · reflex 0 · finish 0。時刻を固定する仕組みは入れていない（実際の利用者にうそをつくため）。
