# NOTES — 03-dash-clinic(今月の給与)

Budget: standard. Surface: product. Mode: build (+ system: DESIGN.md written here).

## Ground
- Subject: 小規模クリニック(15〜40名)向け給与計算SaaSの「今月の給与」画面。
- Audience: 院長・事務長。経理の専門家ではなく、診療の合間に月1回給与を締める。
- Job: 今月の給与を**確定する**。その前段として未承認の勤怠申請を承認する。
- Primary action: 未承認が残っている間は「勤怠を承認する」が唯一の塗りボタン、「給与を確定する」は同じ位置で無効化し理由を横に表示。全件処理後は「給与を確定する」が塗りに替わる。

## Three directions
Usual look: 白地、Inter/Noto Sans、青のプライマリ、大きな数字+小ラベルのKPIカード列、角丸+影のカードにゼブラ表。

- A — 「給与袋」: 昔の現金給与袋(クラフト紙、朱の受領印欄、明朝の印刷見出し)。承認=押印。→ クラフト+明朝+朱で R04a に落ちるため不採用。
- B — 「タイムカード」(採用): スタッフ通用口のラックに差してある月次タイムカードと2色リボンのタイムレコーダー。期間の日付帯が画面を率いる。
- C — 「待合室の番号表示機」: 黒地にアンバーの7セグ数字、暗く大きな数字で残り日数と件数を見せる。→ 患者向け掲示に見え、事務作業の道具に見えないため不採用。

Chosen: B. 地の明度(白→ラックの鋼色の中明度)、表示書体(グロテスク→ドットマトリクス DotGothic16)、主データマーク(KPIカード→打刻の点線と赤の不規則マークを持つ日付帯)の3点で usual から外れる。

## Token plan(要約)
- 色: 台枠(鋼)#CDD1CC / カード #F4EFE2 / 墨(リボン黒紫)#27222F / 薄墨 #5C5566 / 罫の緑(アクセント)#2E6A4B / 罫(入力枠)#6E8777 / 赤リボン #B0232E。
- Accent candidates: 赤リボン(355°)、カードの罫の緑(150°)、リボンの黒紫(ほぼ無彩色)。→ 緑。赤は「不規則=未承認・エラー」の意味に専有させ、黒紫は本文インクと区別がつかないため。
- Display candidates: DotGothic16(ドット)、Shippori Mincho(明朝)、Dela Gothic One(太ゴシック)。→ DotGothic16:レコーダーが印字する文字そのもの。タイトル、3つの主要数値、日付帯の日付、承認リストの日付だけに使用。
- Body: BIZ UDPGothic(UD、年配の読者にも)。Figures: BIZ UDGothic(同ファミリーの等幅版、表の数値)。Google Fonts から読み込み。
- Scale 1.25 / base 16px、spacing 4px、角丸 カード6px・コントロール4px、影はカードの1段のみ。

## Signature
**支給対象期間の日付帯**(10月21日〜11月20日の31マス)。タイムカードの「1日1行」の罫から作った。経過日は墨の点線、未承認申請のある日(9・12・13・14日)は赤の上罫と赤い点、今日(16日)は太枠、締め日までの残り4日は淡い罫色、締め日は二重罫で閉じる。「あと4日」「4件」の数字と同じ事実を日付上で示す。
同じ単位を再利用: スタッフ表の罫(緑の罫・未承認行の赤い左罫・合計行の二重罫)、承認ダイアログのリスト(左にドット書体の日付+罫)、読み込み中の骨組み行。

## Critique rounds
- Round 1(render): 768pxで表が横にはみ出し(F08/R17)、320pxでヘッダーと合計の数値を display:none(R18)。→ 表のブロック化を800px以下に、見出し行は並べ替えボタンの行に、合計行もラベル付きで表示。
- Round 2(目視): 768pxで1人あたりのブロックが縦に長すぎた → 4つの数値を横1列に。768pxで3つの主要数値を縦積みしていた → 520px以下のみ縦積み。日付帯で「あと4日」が見えない → 残り日を淡く塗る。トーストがモーダルの背面に隠れる → 開いているダイアログ内に出す。他の月を見ているのに見出しが「今月の給与」→ 「9月の給与」などに切替。
- Cover-the-signature caption: 「罫線の緑と赤の未承認フラグを持つ、紙の勤怠票のような給与一覧」— usual look のキャプションではない。
- Removed accessory: 表の5行ごとの濃い罫(装飾のみ)。

## States(すべて実際の操作で到達)
- 部分状態(初期表示): 未承認の勤怠申請4件。日付帯の赤、表の「未承認 1件」フラグと赤い左罫、確定ボタン無効+理由。
- 読み込み中: 初回表示と月の切り替え時(約0.25秒)に表の骨組み行と日付帯の灰色マス。
- エラー: 「‹」で9月分へ移動すると1回目はタイムアウトのエラー(role=alert、原因と「再読み込み」)。再読み込みで成功。オフライン時は全月で接続エラー。確定ボタンもオフライン時はダイアログ内にエラーを表示。
- 0件: 「›」で12月分(期間開始前)へ移動すると「12月分の勤怠はまだありません」+「11月分に戻る」。絞り込みで一致なしの場合も「絞り込みを解除する」付きの空状態。
- 承認 → 確定: 承認すると残業代と控除が再計算され合計と前月比が更新。全件処理後「給与を確定する」→ 確認ダイアログ → 「給与を確定しました」トーストと「確定済み」表示。

## Assumptions and invented content
- 給与は20日締め・25日支給と仮定。デモの「今日」は 2026年11月16日(月)に固定(JSの TODAY)。締め日までの残り日数が意味を持つ月中の状態を既定表示にするため。
- クリニック名「あおば通り内科クリニック」、事務長「田村 恭子」、スタッフ18名の氏名・職種・金額、申請4件の内容、前月の支給額、確定時刻(9月18日・10月19日)はすべて架空。控除は(残業の追加分の約11%を加算する)簡易計算で、実際の税・社会保険の計算ではない。
- 日曜と祝日(11月3日など)は休診日として印字なし。
- 9月分の1回目の読み込み失敗はエラー状態を確認するためのモック挙動。
