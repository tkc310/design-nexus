# NOTES — 土と灯 トップページ

Budget: standard / Surface: marketing / Mode: build (+ DESIGN.md を新規作成)

## Ground

- Subject: 京都・五条坂の陶芸工房「土と灯」。職人2名、日常の器(飯碗・湯呑・小皿)、月2回・各回6名までの手びねり教室。
- Audience: 30〜50代の国内外の旅行者。半日を使えるか、手ぶらで行けるか、焼き上がりをどう受け取るかが気になる。
- Job: 体験教室の予約ページへ送る。

## Three directions

- A — 「窯詰めの棚」: 窯に器を詰める棚板と支柱、夜の工房の一灯(=店名の「土」と「灯」)を借りる。暗い土色の地に灯の琥珀。次の3回の教室を棚として積み、1席=1つの器で空席を見せることがページを率いる。
- B — 「釉薬の試験片」: 工房の壁に並ぶ釉薬テストピースの板を借りる。中間調の素地色の地、ヒューマニストサンス、器と教室を試験片のグリッドで並べる。
- C — 「寸法図」: 職人がろくろ脇に貼る器の寸法図とトンボ(竹の計測具)を借りる。白化粧の明るい地、明朝、飯碗を原寸の線画で描き、その寸法から教室の内容へ一列で読ませる。

Chosen: **A**。店名そのもの(土と灯)が暗い土と灯りの関係で、予約という唯一の目的を「残りの席=棚に残った空きの器」として直接見せられるため。B は器が主役になり予約が二次的になる。C は明るい地+明朝で R04a(クリーム+セリフ+テラコッタ)に寄りやすかった。

## Signature

ヒーロー右(320px では見出し直後)の **窯詰めの棚**。次の3回(11/14・11/28・12/12、表示例)を支柱で支えた棚板として縦に積み、各棚に器を6つ載せる。予約済みは灰色の塗りの器、空席は灯色の輪郭の器(塗り/輪郭で形も違うので色だけに頼らない)。棚板の前縁に日付・時間・残席数を書き、棚全体がその日の予約ページへのリンク。読み込み直後から完成状態で表示され、アニメーションなし。

## Challenge で変えたこと

- 陶芸の定番(クリーム地+テラコッタ+明朝=R04a)を捨て、暗い土色の地にした。アクセントは朱ではなく灯の琥珀(R04b の vermilion を避ける)。
- 呉須の青を白磁の地に置く案は R04d(淡い紙+インクブルー)に近いので不採用。
- 器の写真枠は同じカードを3つ並べるのをやめ、各器の径(12 / 7.5 / 10.5cm)に比例した幅で1本の棚線に立たせた。
- 「01/02/03」の番号ではなく、教室の流れは実際の時刻(13:30〜15:40、約2か月後)で並べた。

## Critique rounds (standard: 2 rounds)

1. 320px 指摘: ナビの「器」リンクが 13px 幅で F09 → min-width 44px。ロゴと予約ボタンが1行に収まらない → 狭幅でロゴを縮小、ギャップを詰めた。1280px: 流れの各段で見出し位置がずれる → `align-content: start`。器セクションの大枠1つ+小2つが空白を作る → 径比例の3列+subgrid の棚線に変更。
2. 写真枠と棚線の間に隙間 → subgrid の row-gap を 0。1920px で中央の細い列が浮く → 1600px 以上で幅 1480px、器アイコン 44px。

Remove one accessory: 締めのセクションの灯のグロー(ヒーローの繰り返しで、シグネチャーを薄めていた)を削除。
