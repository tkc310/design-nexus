Search structured logs with a filter, not a regex.

grepline reads JSON and logfmt lines across every file you give it and prints only the records your filter keeps.

Homebrew
brew install grepline
Cargo
cargo install grepline

JSON and logfmt read as the same record

Point grepline at a mix of files. Each line is parsed by its own format, so one filter runs across all of them, and a record missing a field simply doesn't match a condition on it.

api.jsonl JSON, one object per line

{"ts": "2026-10-31T09:14:02.118Z", "level": "error", "route": "/checkout", "status": 502, "latency_ms": 812, "msg": "payment provider timed out"}
