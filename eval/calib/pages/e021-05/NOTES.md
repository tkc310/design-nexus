# NOTES — 05 mobile transit

Budget: standard. Surface: mobile. Mode: build (+ system: DESIGN.md written here).

## Ground
- Subject: 地方都市のコミュニティバス(市内循環1系統)の停留所時刻表。
- Audience: 高齢の利用者が多い住民。屋外・片手・日差しの下。
- Job: 選んだ停留所の「次のバスが何時、あと何分」を知る。

## Three directions
- A — 「停留所の時刻板」: 標柱の白いホーロー時刻板(黒枠、左の「時」列、太い数字、赤い運休の貼り紙、車体の緑帯)を借りる。発車板が先頭、その下に時刻板そのものが続く。
- B — 「車内LED表示器」: バスの行先表示・車内の次停留所LEDを借りる。暗い地に琥珀のドット数字。カウントダウンが先頭。
- C — 「回数券つづり」: 色紙の回数券・乗車券を借りる。中間調の色地、スラブ数字、ミシン目で区切った券面カード。
- Chosen: A。利用者が実物の停留所で毎日見ている時刻板そのものなので読み方の学習がいらず、白地・墨・太字は日差しの下でも高齢者に読みやすい。B は昼の屋外で読みにくく、C は色地でコントラストが取りにくい。

## Accent / display candidates
- Accent: 車体の緑帯 #0A6B3B / 標柱の行先板の青 / 夜の車内灯の琥珀 → 緑。遠くから来るバスを見分ける色がこのバスの色だから。青はよくある「公共の青」、琥珀は白地で 4.5:1 を満たせない。
- Display: Atkinson Hyperlegible(ヒューマニストサンス、ロービジョン向けに 1/7・3/8・0/O を区別)/ Zen Maru Gothic(丸ゴシック)/ DotGothic16(LEDドット)→ Atkinson。時刻板の太いゴシック数字に近く、高齢者が数字を読み違えにくい。本文は BIZ UDPゴシック(公共表示向けUD書体)。

## Signature
「つぎに来るバス」の発車板: 3本の発車時刻と「あと何分」を時刻板の行で大きく出す(1本目は緑のラベル列と 55px の分数)。単位は時刻板の行(左ラベル列+右の数字)で、運休のお知らせ(左列=日付)と全時刻表(左列=時、右=分のチップ)に同じ行を使う。時刻表のチップも発車板と同じ色分け(つぎ=緑塗り、その次=緑枠、運休=赤破線+取消線)で対応している。

## Reflex findings kept
- R18 (render, @320px): 幅 640px 未満では、時刻表の「平日」「土日・祝日」のうち選んでいない列を隠している。ラベル付きの切替(平日/土日・祝日)で必ず出せる。320px で44px以上のチップを2列並べると、とくに「文字を大きく」の時に収まらないため。コードに `design-nexus: keep R18 because ...` を記載。

## Fix rounds
1. 1時間以上の待ち(夜は翌朝の便)で「あと10時間17分」が 320px で崩れた → 1時間以上は数字を一段小さく、数字+単位ごとに改行禁止。ヘッダーとお知らせ日付のはみ出しを修正。お知らせ本文の重複した言い回しを整理。
2. 1280px で土日祝(1時間1本)の1列表が右半分空いた → 幅 640px 以上は 平日|土日・祝日 の2列表(実物の時刻板と同じ)。今日の列見出しに「(きょう)」。文字を大きくした時の 320px のはみ出し(列見出しとセグメントの改行禁止)を修正。ダークではヘッダーの緑の面をやめ、時刻板の面+緑の下線に。
- Removed accessory: 運休チップの赤い地の塗り(赤破線・取消線・「運休」の文字で足りる)。

## States and how to reach them
- 通常: 運行時間内に開く(例: `--time 2026-10-31T11:30:00+09:00`)。
- 本日の運行終了: 最終便の後に開くと、発車板は「きょうの運行は終わりました」と翌運行日の3本(「明日」タグ付き)。
- 運休便: 2026-10-31 の 12:40 発(駅前基準)が時刻表で取消線、発車板の下に赤帯で案内。
- 停留所休止: 2026-11-03 に「中央公園前」を選ぶと全便が運休扱い。
- 全便運休日: 2026-12-29〜2027-01-03 は発車板に案内が出て、再開後の便を表示。
- お知らせなし: すべてのお知らせの日付を過ぎると「いま、運休のお知らせはありません。」
- 文字を大きく: ヘッダーのボタン(状態は localStorage に保存、使えない環境でも動作)。選んだ停留所も保存。
