Search logs by field, not by regex

grepline reads JSON and logfmt lines across many files at once and keeps only the ones that match a filter like level=error and latency_ms>500.

Install with
cargo install grepline

  • Written in Rust
  • MIT licensed
  • One binary

The filter reads like a where clause

Name a field, compare it, join conditions with and and or. Numbers compare as numbers. Each row below runs against the 12 lines above.
FilterKeeps lines whereMatches above
level=error the field equals a value 5 of 12
latency_ms>500 a number is above a threshold (also <, >=, <=) 5 of 12
level=error and latency_ms>500 both conditions hold 3 of 12
service=auth or service=billing either condition holds 6 of 12
level!=info the field is anything but a value 7 of 12

JSON and logfmt, same fields

Point it at a folder that mixes both. Each line is parsed into fields first, so one filter covers every file.

Install, then run your first filter

One binary, MIT licensed. Install it with cargo on any platform Rust builds for, or with Homebrew.

  1. Install
    cargo install grepline

    Or with Homebrew: brew install grepline brew install grepline

  2. Run
    grepline 'level=error and latency_ms>500' logs/
