Query log files like rows in a table.

grepline searches JSON and logfmt logs across as many files as you hand it, and keeps the lines where level=error and latency_ms>500. One Rust binary, MIT licensed.

Install

$ brew install grepline
$ cargo install grepline

Then point it at a directory: grepline 'level=error' logs/*

Filter syntax

Run loads an example into the filter above
  • =level=warnField equals a value. Quote values that contain spaces.
  • !=status!=200Field is present and not equal.
  • > <latency_ms>=1000Numeric comparison with >, >=, < and <=.
  • andlevel=error and latency_ms>500Both conditions hold on the same line.
  • orjob=invoice.render or upstream=searchEither condition holds. Fields missing from a line never match.
  • notnot level=info and not level=debugInverts the condition that follows it.
  • ( )(level=error or level=warn) and latency_ms>=1000Groups conditions; and binds tighter than or.

JSON or logfmt, the filter doesn't change.

The worker writes logfmt, the API writes JSON lines. grepline reads both as fields, so one filter covers the whole directory and the results come back in one shape.
