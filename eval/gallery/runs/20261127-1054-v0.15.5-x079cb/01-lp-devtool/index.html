Filter JSON and logfmt logs like a table.

grepline reads structured logs across many files and keeps the records that match a SQL-like filter.

Install with Homebrew

brew install grepline

or with Cargo

cargo install grepline

Read a filter left to right.

level=errorandlatency_ms>500

  1. level=error

    The field level equals error. The same key works whether the record is JSON or logfmt.

  2. and

    Both sides must hold for a record to stay.

  3. latency_ms>500

    The field latency_ms is greater than 500, compared as a number.
