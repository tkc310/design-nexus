Filter structured logs like rows in a table.

grepline searches JSON and logfmt logs across many files with a SQL-like filter. level=error and latency_ms>500 finds the slow failures in all of them at once.

cargo install grepline
brew install grepline

Written in Rust · MIT licensed · one binary

A filter reads like a WHERE clause.

Name a field, compare it to a value, and join conditions with and. No pipeline of tools, no regex for the shape of each format.

levelfield
=equals
errorvalue
andboth hold
latency_msfield

JSON or logfmt, one filter.

Services rarely agree on a log format. grepline reads both, so the same event matches whichever way it was written.

The whole tool, as one log line.
