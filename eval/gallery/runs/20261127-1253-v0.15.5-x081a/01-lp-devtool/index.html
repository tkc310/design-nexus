Find the slow errors in every log file.

grepline reads JSON and logfmt lines from many files at once and keeps the ones that match a SQL-like filter.

  • brew install grepline
  • cargo install grepline

A filter reads like a WHERE clause.

  1. level=error

    A field from the line, compared with a value.

  2. and

    Both sides must hold.

  3. latency_ms>500

    Numbers compare as numbers, so 1240 passes and 74 doesn’t.

No regex for the shape of a line, no piping through jq first. You name fields, and grepline checks each line from each file against them.

JSON or logfmt, one filter.

Fields are the keys in each line, whichever way the service wrote it. Files from different services go into one search.

  • api.jsonl{"ts":"15:02:10","level":"error","path":"/checkout","latency_ms":903}
  • edge.logts=15:02:10 level=error path=/checkout latency_ms=903

Open source, one binary.
