Search structured logs with a where clause.

grepline reads JSON and logfmt lines across many files and keeps only the ones your filter matches.

brew install grepline

    Mixed formats, one filter

    Your API writes JSON and your workers write logfmt. The same clause reads the fields of both.

    api.json

    {"level":"error",
 "msg":"upstream timeout",
 "path":"/v1/checkout",
 "latency_ms":1204}

    worker.log

    level=error
msg="db deadlock"
queue=billing
latency_ms=2210
    Fields the filter sees in both lines
    levelerror
    msgupstream timeoutdb deadlock
    latency_ms12042210
