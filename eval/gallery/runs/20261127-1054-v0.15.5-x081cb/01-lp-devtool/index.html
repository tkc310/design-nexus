GREPLINE(1)

NAME

grepline — search structured logs across many files with a SQL-like filter

INSTALL

  • macOS, Linux $ brew install grepline

  • with Rust $ cargo install grepline

Written in Rust. MIT licensed. One binary, nothing else to run.

EXAMPLE

filter and

3 of 10 lines match

lines as

    Reading the filter

    level=error
    The level field equals error.
    latency_ms>500
    The latency_ms field is greater than 500.
    and
    A line must meet both conditions.

    Switch a condition off, or change the threshold, to see which lines it was holding back.

    DESCRIPTION

    grepline reads structured log lines, JSON or logfmt, from many files at once and keeps the ones your filter matches. You filter on fields by name, the way you would write a SQL where clause, instead of writing a regex that has to guess where a field starts and ends.

    For the slow errors at 3 a.m., that is one expression: level=error and latency_ms>500.
