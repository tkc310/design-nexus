Query your logs like a table, from the shell.

grepline searches JSON and logfmt logs across many files with a SQL-like filter. One Rust binary, MIT licensed.

Install grepline

  • brew install grepline
  • cargo install grepline

Try

    JSON or logfmt, one filter.

    Mixed services write mixed formats. The same level=error and latency_ms>500 catches this event in both encodings.

    JSON
    {"ts":"2026-11-04T15:29:41Z","service":"checkout","level":"error","latency_ms":1284,"path":"/cart/pay"}
    logfmt
    ts=2026-11-04T15:29:41Z service=checkout level=error latency_ms=1284 path=/cart/pay

    What you're installing.

    One binary to put on a box, in a container, or in CI. Either package manager installs the same one.
