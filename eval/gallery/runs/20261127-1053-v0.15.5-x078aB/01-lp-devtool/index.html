Put a where clause on your logs.

grepline is an open-source CLI that searches JSON and logfmt logs across many files with a SQL-like filter. Type the condition you mean and get the lines that match.

Cargo
cargo install grepline
Homebrew
brew install grepline

Then point it at a directory: grepline 'level=error and latency_ms>500' logs/

This runs in your browser on twelve example lines; the real binary reads your files. Edit the filter and the result updates.

Small enough to read in one line.

Everything there is to know before you install it, in the format it searches.

binaries=1
One executable on your PATH. Nothing to run alongside it.
lang=rust
Written in Rust and published as a crate, so Cargo can build it.
license=MIT
Open source. Read it, fork it, ship it inside your own tooling.
formats=json,logfmt
Both structured formats, across many files, in the same search.

One filter for both formats.

A text search cannot compare numbers, and a JSON tool stops at the first logfmt line. grepline reads fields from either format, so the condition is the whole command.

Install it, then ask the question.

Either command gives you the same single binary.
