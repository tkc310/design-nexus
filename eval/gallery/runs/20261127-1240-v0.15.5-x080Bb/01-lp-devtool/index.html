Filter every JSON and logfmt file with one line.

grepline searches structured logs across many files at once. Write a condition like level=error and latency_ms>500 and it prints the records that match.

$ cargo install grepline

Or with Homebrew: brew install grepline

run it on your own logs

The filter above is the same one you type in your terminal. Install takes one command.

cargocargo install grepline
brewbrew install grepline

JSON and logfmt, read by the same filter.

Your API writes JSON and your workers write logfmt. grepline reads both, so one condition covers the whole incident instead of one tool per format.

edge.log JSON

edge.log:4417 {"ts":"2026-11-04T10:21:31Z", "level":"error", "route":"/api/cart", "latency_ms":1530, "msg":"upstream reset"}

worker.log logfmt

worker.log:902 ts=2026-11-04T10:21:12Z level=error job=invoice.render latency_ms=880 msg="template missing field total"

Both matchlevel=error and latency_ms>500
