Search structured logs with a where clause.

grepline reads JSON and logfmt across many files and keeps only the records your filter matches.

Install with Homebrew or Cargo
brew install grepline
cargo install grepline

grepline at a glance

grepline lang=rust license=MIT binaries=1 reads=json,logfmt install=brew,cargo

A filter reads like the where clause you already write.

Name the fields, compare them, join the conditions. The same filter runs over every file in the search.

  1. levelfield name
  2. =equals
  3. errorvalue
  4. andboth must hold
  5. latency_msfield name
  6. >greater than
  7. 500number

Install one binary.

With Homebrew

brew install grepline

With a Rust toolchain

cargo install grepline
