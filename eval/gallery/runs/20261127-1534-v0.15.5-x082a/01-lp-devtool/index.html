Search logs with a where clause.

grepline is an open-source CLI for JSON and logfmt logs. Write level=error and latency_ms>500 and it searches every file you give it.

Homebrew
brew install grepline
Cargo
cargo install grepline

How a filter reads

Conditions on fields, joined with and, the way you would write a SQL where clause. grepline checks each line in every file against it and keeps the lines where it holds.

level=error
The field level equals error.
and
Both conditions must hold.
latency_ms>500
The field latency_ms is greater than 500.

Install grepline

Use Homebrew, or Cargo if you already have a Rust toolchain. Either way you get one binary.

Homebrew
brew install grepline
Cargo
cargo install grepline
