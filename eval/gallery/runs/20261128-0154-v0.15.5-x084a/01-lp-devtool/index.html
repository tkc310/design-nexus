Filter logs like a table, not like a string.

grepline searches JSON and logfmt logs across many files with a SQL-like filter. One Rust binary, MIT licensed.

  • $ brew install grepline
  • $ cargo install grepline

What you install

written_in=rust
Built as a native executable from Rust source.
license=MIT
Use it at work, change it, ship it inside your own tooling.
binaries=1
One file on your PATH. Remove it and it is gone.
reads=json,logfmt
Structured logs in either format, searched across many files.

Read the filter like a WHERE clause.

level=error

A field equals a value. The field is a key in each log line.

and

Both conditions must hold.

latency_ms>500

Compares the field's value as a number.

Field names are whatever your services already log, so the filter you write during an incident uses the same words as your dashboards.

Put it on your PATH.

  • $ brew install grepline
  • $ cargo install grepline
