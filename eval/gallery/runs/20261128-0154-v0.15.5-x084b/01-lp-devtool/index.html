Filter syntax Install

Query your logs like a table, across every file at once.

grepline searches JSON and logfmt logs with a SQL-like filter, so level=error and latency_ms>500 finds the slow failures wherever they were written.

brew install grepline
cargo install grepline

lang=rust license=MIT binaries=1 formats=json,logfmt

A filter reads the way you'd say it out loud.

  1. levela field in the record=equalserrorthe value to keep
  2. andboth sides must hold
  3. latency_msanother field>greater than500the threshold

No regex to escape and no jq pipeline to remember: you name fields, compare them, and join the comparisons with and.
