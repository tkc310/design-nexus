Query every log file by field.

grepline searches JSON and logfmt logs across many files with a SQL-like filter. Write level=error and latency_ms>500 and keep only the lines where it holds.

Install with
brew install grepline cargo install grepline

grepline at a glance

about.logfmt:1lang=rust license=MIT binaries=1 formats=json,logfmt installs=brew,cargo

Read the filter left to right

level=error and latency_ms>500
level=error
The record’s level field equals error, whether the line is JSON or logfmt.
and
Both sides must hold for a line to be kept. Untick either clause above to see what it was removing.
latency_ms>500
The latency_ms field is greater than 500.

Install

Homebrewbrew install grepline
Cargocargo install grepline

Either way you get the same single binary. Then filter with level=error and latency_ms>500.
