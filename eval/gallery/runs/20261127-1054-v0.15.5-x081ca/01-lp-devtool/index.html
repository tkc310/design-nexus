Search JSON and logfmt logs with level=error instead of a regex.

grepline reads structured log lines across many files and keeps the ones that match a SQL-like filter. It's a single open-source binary written in Rust.

  • $ homebrew brew install grepline
  • $ cargo cargo install grepline
