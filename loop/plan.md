## 診断

頭打ちの主因は2つある。

- **計器の問題**: 付帯条件(守り)の閾値が雑音より細かかった。そこに選ばれた base が重なり、EXP-026 を落とした。
- **仮説の選び方**: 多くの仮説が、対比較の勝ち負けを決めない傷を1つずつ消す型だった。

EXP-026 の変更そのものは、これまでで最も強い効果を示した。捨てる理由はない。

### 1. 計器: 生成のばらつきが大きく、守りの閾値がそれより細かい

- **生成1回のばらつきが、効果と同じくらい大きい。**
  - 同じ内容の版でも、学習用6件の平均が 3.2 点違った(M-005)。
  - 同じ版の検証用6件で、審査の平均が 51.25 と 46.1 だった(v0.6.0 の2回)。
  - 同じ版を2回生成すると、審査はそろって2つを見分けた(M-008)。
  - 同じ D2 の文から、D2 が 0–4 のページも 7–0 のページも出た(EXP-026 の計画)。
- **絶対点は、D2 と D6 でほとんど動かない。**
  - 学習用の D2 は 150 判定中 119 が3点。D6 は 416 判定中 404 が3点(EXP-024・026 の計画)。
  - 感度があるのは対比較だけ(M-008)。
- **clear の判定は少なく、段階1の検出力は低い。**
  - 対比較で clear 以上になったのは、EXP-021〜026b の 78 判定中 30。
  - 12対の clear net の標準偏差は、対が独立でも約2。1ページが2対に出るので、実際はもっと大きい。
  - 三項分布で計算すると、段階1(+3 で採用、0 以下で却下)には次の性質がある。
    - 効果がなくても、約1割が採用される。
    - clear 勝ち3割・負け1割の中くらいの効果でも、採用は約5割にとどまる。
- **1次元ずつの守りが、効果がなくても高い確率で働く。**
  - 1次元の net の標準偏差は、12対で約3。
  - EXP-026 の守りは「D3・D7・D8・D9 がそれぞれ −3 以上」だった。
  - 同じ base とケースの対照の率で計算した。対照は EXP-024・025 の Opus 12対で、D3 −2、D7 +4、D8 −2、D9 +6。
  - 効果がなくても、どれかが −4 以下になる確率は約6割あった。
  - D8 の対照は −2 なので、閾値 −3 には1敗分の余裕しかなかった。
  - 誤りは、採用基準と同じ大きさ(n/4)を1次元ずつ当てたこと。その次元の、効果がないときの期待値もばらつきも見ていなかった。
- **まとめ**
  - 中くらいの効果の仮説でも、守りまで通る確率は3割前後しかない。
  - 良い仮説を出していても、3連続の却下は珍しくない。
  - STALLED の一部は、計器の性能による。

### 7. メインのセッションの案(EXP-026 + D8 を守る最小の追記)について

**勧めない。理由は4つ。**

1. **D8 の負けは、大半が構造と雑音。** D8 −5 のうち −4 は 01 の base の構造で、残りは雑音の範囲。同じ base と同じ守りのままなら、D8 を追記しても 01 の −4 は消えない。また守りで落ちる見込みが高い。
2. **的が違う。** 対照より大きく落ちたのは D7 と D1。
3. **帰属できなくなる。** 2つの変更を同時に入れると、通っても落ちても、どちらが効いたか分からない。EXP-026 との比較もできなくなる。
4. **やめるべき型そのもの。** D8 の追記は、決め手でない傷を消す型。状態が主な決め手になった clear は0件。

**代わりに、次の順で進める。**

- 次は EXP-026 を1字も変えずに、直した計器で再現する(仮説1)。直す点は3つ。選ばれていない新しい base、盲検、雑音に合わせた守り。
- D7 は、再現のあとに計画の段で扱う(仮説2)。
- どうしても何か足すなら、1句に限る。EXP-026 の「never by adding a part」は、状態や操作の追加まで止めると読める。この句を、その文の中で「飾りの部品に限る」と絞る。

### 2. EXP-028: 幅ごとの形を、計画の段で決める

### M-013 守りを、雑音の大きさと対照に合わせる

**理由**

**変更**

- **守る次元を絞る**: 仮説の「予想される失敗」に挙げた2〜3個に限る。
- **却下の条件**: 次のどちらかのときだけ却下する。
  - 守る次元の net が −n/2 以下(12対で −6、18対で −9)。
  - 同じ次元を決め手にした clear 負けが2件以上。

- **要観察の帯**: −n/4 から −n/2 の間は「要観察」とする。
  - 理由を読み、ケース別の内訳で、構造的な偏りか、変更の仕組みかを分けて記録する。構造的な偏りとは、同じ base ページがどの候補にも勝つこと。

- **旧 base を使うとき**: 選ばれた base を使わざるを得ないときは、同じ base に対する過去の候補(対照)の net との差に、同じ閾値を当てる。
- **報告に添えるもの**: pair-score と experiments.md の結果に、次を必ず添える。±1 標準偏差以内の次元は「差なし」と書く。

  - ケース別と run 別の内訳
  - 雑音の目安: 12対で、clear net の標準偏差は約2、1次元は約3。

**費用**: なし(集計と書き方だけ)。

**確かめ方**: 次の3実験で、守りが働いた回数を数える。要観察の次元が、次の run でも同じ向きに出るかを見る。
