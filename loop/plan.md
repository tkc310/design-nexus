1. **目標と採否の計器が、別のものを測っている。**

### M-025 採用の道を2つにする(経路 P: 対比較、経路 C: 基準)

**理由**

- 診断1・3のとおり、目標は v2 の 92 だが、採用の道は対比較だけ。v2 の失点の上位は、対比較の決め手にならない。

- M-021 が平均点で決めることを避けた理由は、ページのばらつきと審査のゆらぎだった。これは、狙った基準の満たす率には当たりにくい。
  - 効けば大きく動く(EXP-029 の D2.2 は 0.42 → 1.0)。
  - ツールがあれば、審査に頼らずに数えられる。

**変更**

- 仮説を書くときに経路を先に決め、v2 の基準と対比較の両方の予想を書く。
- **経路 P(対比較)**: 採用の手順 a〜g のまま。ただし段階2(+1・+2 で生成を足す)は、守る次元のどれも −n/4 以下でないときだけ行う。どれかが −n/4 以下なら、段階1で却下する。
- **経路 C(基準)**: 次をすべて満たせば採用する。
  1. 新しい Floor がなく、どのケースにも新しい拒否権がない。出たら、手順 f のとおり根拠を読む。
  2. ツールがある場合は、ツールが出る候補のページが6ページ中1以下で、base の12ページでは4ページ以上に出ている。base で出ることが、ツールが審査の欠陥を捉えている証拠になる。
  3. 狙った基準(先に決めた1〜6個)を合わせた満たす率の上がり幅が、min(0.3, base の不合格の率の半分) 以上。
     - ツールがなければ、候補を2回生成した12ページで測る。
     - 1回目の6ページで届かなければ、2回目を作らずに却下する。
  4. 害がない。いずれも1回目の12対で見る。
     - clear net が −2 以上。
     - 守る次元(2〜3個)が、それぞれ −n/2 より上。
     - 変更そのものを決め手にした clear 負けが1件以下。
  5. `compare --scale v2` で HOLD がない。狙った以外で満たす率が 0.5 以上下がった基準があれば、根拠を読む。同じ具体的な欠陥を指していれば却下する。
- 両方の経路の条件を満たしたら、経路 P として記録する。
- 版: ツールだけの変更は patch、本文の規則の変更は minor。
- 確かめ方: 経路 C で採った変更は、次の base(新しい版の2回)でも、狙った基準の満たす率が保たれたかを見る。保たれなければ記録し、次の見直しの材料にする。

**費用**
